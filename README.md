# Railway PPP Dashboard

Standalone React/Vite version of the Claude Artifact.

## Deploy
1. Upload this project to a GitHub repository.
2. Import that repository into Vercel.
3. Vercel will detect Vite automatically.
4. Build command: `npm run build`
5. Output directory: `dist`

The Claude Artifact hosting header is not part of `src/App.jsx`; it is supplied by Claude's artifact page. This project hosts the dashboard itself.
